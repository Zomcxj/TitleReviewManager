# 功能说明

## 完整功能列表

### 用户与认证
- 用户登录/登出
- JWT Token 认证（15 分钟过期）
- 基于角色的访问控制（RBAC）
- 密码 bcrypt 加密存储

### 客户管理
- 客户信息 CRUD
- 客户列表搜索/筛选
- 客户详情页
- 客户分配（业务员）
- 批量分配客户

### 申请管理
- 申请表单填写
- 申请材料上传
- 申请状态跟踪
- 申请审核
- 审核反馈

### 审核工作台
- 待审核列表
- 审核通过/不通过
- 批量审核
- 审核意见填写

### 通知中心
- 系统通知列表
- 未读消息提醒
- 自动通知（状态变更触发）
- 通知标记已读

### 跟进记录
- 添加跟进记录
- 跟进时间轴展示
- 最后跟进时间追踪

### 公海池管理
- 公海池客户列表
- 领取公海客户
- 释放客户到公海
- 公海池统计（总数、今日领取、超时、即将超时）

### SLA 监控
- 7 天无跟进自动检测
- 超时客户自动回收到公海池
- 后台定时任务调度

### 审计日志
- 操作记录查询
- 按用户/操作类型/资源筛选
- 管理员专属功能

### 数据导出
- 客户列表导出 Excel
- 支持筛选条件导出

### 数据看板
- 统计卡片（客户总数、申请总数、待审核、已通过等）
- 申请状态分布
- 业务员业绩统计
- 趋势分析（按日期统计申请量）

### 其他功能
- 注册链接生成（用于客户自助注册）
- 审计日志查询（管理员）
- 404 页面
