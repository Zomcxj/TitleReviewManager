# 功能说明

## 完整功能列表

### 用户与认证
- 用户登录/登出
- JWT Token 认证（HTTP-only Cookie）
- 基于角色的访问控制（RBAC：管理员/业务员/审核员）
- 密码 bcrypt 加密存储
- 登录限流与账号锁定（5 次失败锁定 15 分钟）
- 用户管理（管理员：创建/编辑/删除用户）
- 自助修改密码

### 客户管理
- 客户信息 CRUD（含拼音首字母自动填充）
- 客户列表搜索/筛选（关键词、状态、分页）
- 客户详情页（基本信息、项目经历、所有申报批次）
- 客户分配（业务员）
- 批量分配客户
- NAS 目录自动创建（按年/业务员/客户）

### 申请管理
- 申请表单填写
- 状态机流转（6 种状态，严格约束）
- 申请材料上传/删除/版本管理
- 申请状态跟踪
- 二次申报（基于不通过批次重新申报）

### 材料管理
- NAS 目录模板存储：`{year}/{salesman}/{customer}_{pinyin}/{category_number}-{category_name}/{filename}`
- 保留原始文件名，同名自动加后缀
- 按类别分组，版本管理
- 文件预览（图片内联 / PDF 新标签页）
- 文件目录树浏览（NAS 视角）
- 关键词/类别/审核状态筛选
- 文件操作审计日志
- 上传限流（50MB，白名单扩展名）

### 存储架构
- 存储后端抽象层（Storage Abstraction Layer）
- 支持本地文件系统或 SMB NAS
- 目录模板可配置（`customer_dir()` 函数）
- 拼音首字母自动计算（Unicode 范围映射，无需 pypinyin）
- 文件审计日志（`file_audit.log`）

### 审核工作台
- 待审核材料列表
- 单份/批量审核
- 审核通过/退回（含问题类型标注）
- 审核意见填写
- 修订稿上传

### 通知中心
- 系统通知列表
- 未读消息提醒铃铛
- 自动通知（状态变更、审核分配等）
- 通知标记已读

### 跟进记录
- 添加跟进记录
- 跟进时间轴展示
- 最后跟进时间追踪

### 公海池管理
- 公海池客户列表（关键词筛选）
- 领取公海客户（每人限额 200）
- 释放客户到公海
- 公海池统计（总数、今日领取、超时、即将超时）
- SLA 定时器：7 天无跟进自动释放，14 天超时

### 审计日志
- 操作记录查询
- 按用户/操作类型/资源筛选
- 管理员专属功能

### 批量导入/导出
- Excel 批量导入客户（xlsx/xls）
- 支持客户列表导出 Excel
- 支持申报批次导出 Excel
- 导入结果展示（成功数/失败详情）

### 数据看板
- 统计卡片（客户总数、申请总数、今日/本周新增）
- 申请状态分布图
- 业务员业绩排名
- 趋势分析（按日期统计申请量）

### 部署
- Docker 容器化（`docker-compose.yml`）
- 支持 SQLite（开发）/ PostgreSQL（生产）
- 前端 Vite 热更新 / 生产构建
- CORS 白名单配置
- 全局异常处理

### 其他功能
- 注册链接生成（用于客户自助注册）
- 审计日志查询（管理员）
- 响应式侧边栏（可折叠）
- 404 页面
